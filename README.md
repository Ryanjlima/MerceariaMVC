🛒 MerceariaMVC
📌 Sobre o projeto
O MerceariaMVC é um sistema web desenvolvido no Visual Studio com ASP.NET Core, criado com o objetivo de aplicar os conceitos de CRUD (Create, Read, Update e Delete) no gerenciamento completo de uma mercearia.
O sistema possui telas interativas para a gestão de Clientes, Produtos e Vendas, permitindo cadastrar, listar, editar, consultar detalhes e excluir registros de forma prática e organizada.

🎯 Objetivo
O principal objetivo do projeto é desenvolver uma aplicação web robusta utilizando o padrão arquitetural MVC (Model-View-Controller) e colocar em prática o controle e gerenciamento completo de informações de um comércio de mercearia.
O sistema foi desenvolvido como projeto de estudo/prática de desenvolvimento web, trabalhando conceitos como:

Model View Controller (MVC)

Rotas e navegação

Formulários dinâmicos

Listagem e paginação de dados

Cadastro e validação de registros

Edição e atualização de dados

Visualização de detalhes

Exclusão de registros com confirmação

📋 Funcionalidades

👥 Clientes
A área de clientes permite:

Cadastrar novos clientes;

Listar clientes cadastrados;

Editar informações pessoais e de contato;

Visualizar detalhes completos do cliente;

Excluir registros do sistema.

Informações apresentadas no cadastro incluem: Nome, Telefone, E-mail, Endereço e CPF/CNPJ.

📦 Produtos
A área de produtos permite:

Cadastrar itens do estoque com descrição, categoria, quantidade e preço unitário;

Gerenciar a quantidade disponível em estoque;

Editar informações de produtos existentes;

Consultar ficha detalhada do produto;

Excluir produtos fora de linha ou descontinuados.

🛒 Vendas / Pedidos
A área de vendas permite:

Registrar novos pedidos de compra vinculados aos clientes;

Listar o histórico de vendas realizadas;

Consultar detalhes de cada pedido efetuado;

Cancelar ou excluir registros de vendas.
